# Skill: Modify LangGraph Node
**Description**: Add, modify, or debug nodes in the LangGraph workflow
**When to use**:
- Adding new workflow nodes (placement, grammar, vocabulary, translation, writing, niveau)
- Modifying existing node logic or prompts
- Debugging graph state transitions
- Updating node dependencies or Neo4j integrations

**Key files**:
- `src/italianollama/graph/nodes/` (all node files)
- `src/italianollama/graph/graph.py` (graph construction)
- `src/italianollama/graph/state.py` (TutorState model)
- `src/italianollama/graph/nodes/base.py` (LLMClient base class)

**Important patterns**:
- All nodes are async functions: `async def node_name(state: TutorState, neo4j_client: Neo4jClient) -> TutorState`
- Use `LLMClient` for API calls (chat/chat_with_json methods)
- Update state dict with new values, return complete state
- Store results in Neo4j via `neo4j_client` methods
- Follow existing prompt style with triple-quoted strings

**Example**:
```python
async def new_node(state: TutorState, neo4j_client: Neo4jClient) -> TutorState:
    llm = LLMClient()
    response = await llm.chat(messages=state["messages"], system_prompt=YOUR_PROMPT)
    state["response"] = response
    await neo4j_client.some_operation(state["student_id"], ...)
    return state
```

**Example**:
```python
@app.get("/api/student/{student_id}")
async def get_student(

        return StudentResponse(**student)
    except NotFoundError as e:
        raise HTTPException(status_code=404, detail=str(e))
```

# Skill: Modify Neo4j Data Models
**Description**: Add or modify Neo4j nodes, relationships, and query patterns
**When to use**:
- Adding new entity types (students, vocabulary, grammar errors, sessions)
- Modifying existing graph schema
- Adding Cypher query methods
- Optimizing data retrieval patterns

**Key files**:
- `src/italianollama/memory/neo4j_client.py` (unified client)
- `src/italianollama/memory/*.py` (manager classes)
- `src/italianollama/graph/nodes/base.py` (LLMClient)

**Manager classes**:
- `StudentManager`: Student CRUD, profile, level
- `LearningManager`: Vocabulary, exercises, errors, flashcards
- `PlacementTestManager`: Test sessions and results
- `AnalyticsManager`: Learning analytics, visualizations
- `ChatManager`: Message storage and retrieval

**Important patterns**:
- All methods are async: `async def method(...) -> Optional[dict]`
- Use parameterized Cypher queries (prevents injection)
- Return dictionaries or lists of dictionaries
- Handle None/empty results gracefully

**Example**:
```python
async def add_vocabulary(self, student_id: str, word: str, level: str) -> dict:
    query = """
    MERGE (s:Student {student_id: $student_id})
    MERGE (w:Vocabulary {word: $word})
    ON CREATE SET w.level = $level, w.created = datetime()
    ON MATCH SET w.level = $level
    MERGE (s)-[:LEARNED]->(w)
    RETURN w
    """
    result = await self._execute(query, student_id=student_id, word=word, level=level)
    return result.single() if result else None
```

async def test_placement_node_new_student():
    with patch("italianollama.graph.nodes.placement.LLMClient") as mock_llm:

        state = {"messages": [], "student_id": "test-123"}
        result = await placement_node(state, mock_neo4j_client)
        assert result["current_level"] == "B1"
